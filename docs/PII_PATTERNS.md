# PII 패턴 사전 (한국 금융권)

> 본 사전은 9장 Input Filter 구현의 입력값. 새로운 패턴 발견 시 누적 갱신.

## 1. 정규식 패턴

| 종류                   | 정규식                           | 마스킹 결과         | 우선순위 |
| ---------------------- | -------------------------------- | ------------------- | :------: |
| 주민번호 (하이픈 포함) | `\b\d{6}-[1-4]\d{6}\b`           | `[RRN_MASKED]`      |    1     |
| 주민번호 (하이픈 없음) | `\b\d{6}[1-4]\d{6}\b`            | `[RRN_MASKED]`      |    1     |
| 외국인등록번호         | `\b\d{6}-[5-8]\d{6}\b`           | `[FRN_MASKED]`      |    1     |
| 신용카드번호           | `\b\d{4}-\d{4}-\d{4}-\d{4}\b`    | `[CARD_MASKED]`     |    2     |
| 계좌번호 (하이픈)      | `\b\d{2,6}-\d{2,6}-\d{2,6}\b`    | `[ACCT_MASKED]`     |    2     |
| 휴대전화               | `\b01[016789]-?\d{3,4}-?\d{4}\b` | `[PHONE_MASKED]`    |    3     |
| 사업자등록번호         | `\b\d{3}-\d{2}-\d{5}\b`          | `[BIZ_MASKED]`      |    3     |
| 이메일                 | `\b[\w.-]+@[\w.-]+\.\w+\b`       | `[EMAIL_MASKED]`    |    4     |
| 여권번호               | `\b[A-Z]{1,2}\d{7,8}\b`          | `[PASSPORT_MASKED]` |    4     |

## 2. NER (선택, 9장에서 적용)

이름 + 생년월일 결합 등 정규식으로 잡기 어려운 패턴은 9장에서 한국어 NER 모델(KoBERT NER 등)로 보강한다.

## 3. 마스킹 정책

- **PII_MASK_LEVEL=off**: 검사 안 함 (개발용, 운영 금지)
- **PII_MASK_LEVEL=basic**: 정규식만
- **PII_MASK_LEVEL=strict**: 정규식 + NER + 결합 탐지

## 4. 동작 분기

| 탐지 시점          | PII 종류                | 동작                  |
| ------------------ | ----------------------- | --------------------- |
| 입력 (사용자 → AI) | 주민번호/외국인등록번호 | 즉시 차단 (요청 거부) |
| 입력               | 그 외                   | 마스킹 후 진행        |
| 출력 (AI → 사용자) | 모든 PII                | 마스킹                |

## 5. 테스트 케이스

"제 주민번호는 901010-1234567 입니다." → 차단
"홍길동님의 계좌 110-123-456789 잔고 알려줘" → "홍길동님의 계좌 [ACCT_MASKED] 잔고 알려줘"
"010-1234-5678로 연락주세요" → "[PHONE_MASKED]로 연락주세요"
"국민은행 1234-5678-9012-3456 카드 사용 내역" → "국민은행 [CARD_MASKED] 카드 사용 내역"
